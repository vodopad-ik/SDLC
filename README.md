## О проекте

Приложение для расчёта суточной нормы употребления протеина (вариант 6).
Пользователь вводит вес тела и выбирает единицу измерения (килограммы или
фунты). Программа переводит вес в килограммы и рассчитывает суточную норму
протеина в граммах.

Особенности:

- язык реализации: C++;
- графический интерфейс: Qt (Widgets);
- система сборки: CMake;
- архитектурный паттерн: MVC с активной моделью (механизм сигналов и слотов Qt);
- последние введённые значения запоминаются и восстанавливаются при повторном
  вводе;
- при некорректных данных выводится сообщение об ошибке.

## Структура проекта

| Модуль      | Назначение                                          |
|-------------|-----------------------------------------------------|
| `model`     | активная модель (данные, расчёт нормы, сигналы)     |
| `view`      | главное окно и окно ввода данных                    |
| `controller`| связь представления с моделью, обработка действий   |
