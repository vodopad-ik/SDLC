# ADR 0001 — Целевая ОС: Windows 11

- **Статус**: принято (2026-10-18)

## Контекст
Нужна невидимость окна при демонстрации экрана, захват звука собеседника и максимальная скорость
на машине Intel Core Ultra 5 125H (Arc iGPU, NPU), 24 ГБ RAM.

## Решение
Первая и единственная целевая платформа MVP — Windows 11 x64 (минимум Windows 10 2004, build 19041).

## Обоснование
- `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` — системный механизм исключения окна из захвата,
  соблюдается DXGI Desktop Duplication, Windows.Graphics.Capture и BitBlt, т.е. всеми приложениями звонков.
  В Linux (X11, Wayland/PipeWire) аналога нет — невидимость там недостижима на уровне ОС.
- WASAPI loopback и process loopback дают захват системного звука и звука конкретного процесса без драйверов.
- Лучшая поддержка драйверов Intel Arc/NPU и OpenVINO (на будущее для локальных моделей).

## Последствия
- Платформенный код (audio, overlay, hotkeys, credentials) изолируется за интерфейсами для будущего порта.
- Linux-порт потеряет стелс-функцию — будет задокументировано как ограничение.
