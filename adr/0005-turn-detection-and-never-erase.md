# ADR 0005 — Определение конца хода и инвариант «никогда не затирать»

- **Статус**: принято (2026-10-18)

## Контекст
Плохой сценарий: собеседник сказал одно предложение → ассистент начал выводить ответ → собеседник продолжил →
ответ стёрт и сгенерирован заново. Это отвлекает и делает инструмент бесполезным в живом разговоре.

## Решение
1. Локальный Silero VAD (ONNX Runtime, CPU) + финальные сегменты STT + эвристики завершённости фразы
   (+ опциональный классификатор Flash-Lite) → `TurnDetector` (конечный автомат Idle → Speaking → PendingEnd → Committed).
2. Коммит хода: тишина ≥ `T_min` (600 мс) и фраза завершена, либо тишина ≥ `T_max` (1800 мс), либо хоткей «Ответить сейчас».
3. **Спекулятивная генерация** стартует в `PendingEnd` (~350 мс тишины), результат буферизуется и не показывается;
   при возобновлении речи — молча отменяется; при коммите — мгновенно выводится. Скрывает TTFT модели.
4. **Показанная карточка неизменяема.** Речь после коммита → новая карточка «дополнение».
   Перегенерация — только по явной команде, создаёт новую карточку.
5. В режиме перевода — append-only по финальным сегментам; перезаписывается только live-строка interim.
6. Протокол API не содержит операций удаления/замены текста карточки.

## Последствия
- Логика детерминирована и тестируется таймлайнами событий с `FakeClock`.
- Параметры настраиваемые и тюнингуются на записях реальных звонков (фаза 6).
- Любое изменение логики — правка этого ADR + новые таймлайн-тесты.
